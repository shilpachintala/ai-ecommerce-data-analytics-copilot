# Dashboard specification
1. Executive Overview — Revenue, Orders, Customers, AOV, Return Rate
2. Customer & Cohort Analysis — RFM, repeat rate, cohort matrix
3. Product Performance — revenue, returns, ratings, discount analysis
4. Funnel & Experiment — view/cart/checkout/purchase + A/B result
5. AI / Risk Insights — anomaly list + validated AI summary

Use a star schema with Date, Customer, Product and Channel dimensions around FactOrder.
