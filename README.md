# AI-Assisted E-Commerce Customer & Sales Analytics Copilot

End-to-end **Data Analyst portfolio project** using SQL, Python, Power BI, Statistics and Generative AI.

> All data is synthetic. No employer or customer-confidential information is used.

## Business problem
An e-commerce leadership team needs one analytical view of revenue, customer retention, product performance, funnel conversion, returns, experiments, anomalies and decision-ready insights.

## What this project demonstrates
- Advanced SQL: joins, CTEs, window functions, views and KPI logic
- Python: Pandas, NumPy, SciPy and scikit-learn
- EDA, data cleaning, validation and anomaly detection
- RFM segmentation and cohort-ready customer analysis
- A/B testing and hypothesis-driven analysis
- Power BI star-schema design and DAX KPI definitions
- Guarded GenAI insight generation from validated metrics
- Git/GitHub workflow and automated data-quality checks

## Repository structure
```text
data/       synthetic source + processed KPI datasets
```
